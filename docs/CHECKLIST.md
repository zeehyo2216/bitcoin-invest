# 리눅스 서버 배포 체크리스트

> 📍 위치: `Docs/CHECKLIST.md`

## ✅ 배포 전 확인사항

### 환경 설정
- [ ] Python 3.8 이상 설치 확인 (`python3 --version`)
- [ ] 프로젝트 파일 서버에 업로드 완료
- [ ] `.env` 파일 생성 및 API 키 설정 완료
- [ ] API 키 권한 확인 (선물 거래 활성화)
- [ ] 테스트넷에서 먼저 테스트 완료

### 파일 권한
- [ ] `deploy.sh` 실행 권한 부여 (`chmod +x deploy.sh`)
- [ ] `.env` 파일 권한 설정 (`chmod 600 .env`)
- [ ] 로그 디렉토리 생성 및 권한 확인

### 의존성
- [ ] `requirements.txt` 확인
- [ ] 가상환경 생성 (선택사항)
- [ ] 모든 패키지 설치 완료

## 🚀 배포 실행

### Step 1: 배포 스크립트 실행
```bash
./deploy.sh
```

### Step 2: 테스트 실행
```bash
python3 main.py
# Ctrl+C로 종료하여 정상 작동 확인
```

### Step 3: 서비스 등록 (선택사항)
- [ ] `trading-bot.service` 파일 경로 수정
- [ ] systemd 서비스 등록
- [ ] 서비스 시작 및 상태 확인

## 🔧 문제 발생 시

### 봇이 시작되지 않음
1. 로그 확인: `tail -f logs/trading_bot_*.log`
2. Python 경로 확인: `which python3`
3. 의존성 확인: `pip list`

### API 오류
1. API 키 확인
2. 네트워크 연결 확인
3. 방화벽 설정 확인

### 메모리 부족
1. 리소스 사용량 확인: `top`
2. 로그 파일 크기 확인
3. 서비스 파일의 MemoryLimit 조정
